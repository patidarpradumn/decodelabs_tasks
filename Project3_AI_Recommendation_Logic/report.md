# Report: AI Recommendation Logic

## Introduction
A recommendation system suggests relevant items to users based on their interests or behavior. This project uses content-based filtering to recommend courses based on user preferences.

## Objective
The objective is to create a simple recommendation system that takes user input and recommends relevant items using similarity logic.

## Methodology
1. A dataset of courses and tags is created.
2. User enters interests.
3. Course tags and user interests are converted into numerical vectors using TF-IDF.
4. Cosine similarity is used to calculate similarity between user interest and course tags.
5. Top matching courses are displayed as recommendations.

## Concepts Used
- Content-Based Filtering
- TF-IDF
- Cosine Similarity
- Similarity Score
- Ranked Recommendations

## Requirements Covered
- User input
- Preference matching
- Recommendation output
- Logic building
- Pattern matching

## Conclusion
This project helped in understanding how recommendation systems match user preferences with item attributes using similarity logic.
