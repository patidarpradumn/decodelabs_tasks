# Task 1: Rule-Based AI Chatbot

## Objective
Create a simple rule-based chatbot that responds to predefined user inputs.

## Features
- Handles greetings
- Handles AI, Python, internship, project, resume, and GitHub queries
- Uses input sanitization
- Uses rule-based matching
- Runs in a continuous loop
- Provides fallback response
- Handles exit commands

## How to Run
```bash
python chatbot.py
```

## Sample Inputs
```text
hello
what is ai
python
internship
project
resume
bye
```
