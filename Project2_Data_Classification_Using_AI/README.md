# Task 2: Data Classification Using AI

## Objective
Build a basic classification model using a small dataset.

## Project Idea
This project predicts whether a student is likely to be placed or not based on:
- CGPA
- Attendance
- Coding Score
- Number of Projects

## Algorithm Used
K-Nearest Neighbors (KNN)

## Requirements Covered
- Dataset loading
- Train-test split
- Feature scaling
- Classification algorithm
- Model training
- Prediction
- Accuracy
- Confusion Matrix
- F1 Score

## How to Run
```bash
pip install -r requirements.txt
python placement_prediction.py
```
