# Report: Data Classification Using AI

## Introduction
This project is a supervised machine learning classification project. It predicts whether a student is likely to be placed or not based on academic and skill-related features.

## Objective
The objective is to build a basic AI classification model using a small dataset and evaluate model performance.

## Dataset
The dataset contains:
- CGPA
- Attendance
- Coding Score
- Number of Projects
- Placement Status

## Methodology
1. Loaded the dataset using Pandas.
2. Separated features and target variable.
3. Split the data into training and testing sets.
4. Applied StandardScaler for feature scaling.
5. Trained a KNN classifier.
6. Predicted placement status.
7. Evaluated the model using Accuracy, Confusion Matrix, and F1 Score.

## Conclusion
This project helped in understanding supervised learning, classification, model training, testing, and evaluation.
